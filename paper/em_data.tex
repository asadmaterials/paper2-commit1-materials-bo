% Data and code availability (shared by main.tex and main_rsc.tex)
The registered analysis plan is archived at Zenodo, version 1.1\cite{asad2026registration} amending version
1.0\cite{asad2026registrationv1}, and the raw Materials Project snapshot used here is archived separately\cite{asad2026snapshot}.
The code (data extraction, benchmark construction, search engine, analysis and tests), all derived data with their SHA-256
hashes, the 7,020 confirmatory run records with their batch manifest and log, the registered and post hoc analysis outputs, the
decision log and this manuscript's sources are available at \url{https://github.com/asadmaterials/paper2-commit1-materials-bo}
(tag \texttt{dd-submission-v1}) and archived at Zenodo (doi:\href{https://doi.org/10.5281/zenodo.23609053}{10.5281/zenodo.23609053}). Every number in the text, tables and
figures is generated from the committed outputs by \texttt{code/make\_numbers.py}, \texttt{code/make\_supplement\_tables.py} and
\texttt{code/make\_figures.py}.
